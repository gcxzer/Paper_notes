# skills

Bundled Paper Notes skills. Each subdirectory is a local instruction package
loaded by the `skills_list` and `skill_view` tools.

## Subdirectories

- `file-artifact-creator/`: Skill guidance for creating downloadable file artifacts.
- `image-artifact-creator/`: Skill guidance for creating generated image artifacts.
- `skill-creator/`: Skill guidance for creating or editing Paper Notes skills.
